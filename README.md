# FASCO Store

Fashion e-commerce UI: catalogue, product pages, cart, and wishlist. Client-side search, validated forms, and Zustand state. Multi-page React app from Figma.

**Live:** [albert-braun.github.io/Online-clothing-store](https://albert-braun.github.io/Online-clothing-store/)

## What it does

- **Cart and wishlist** — persisted in `localStorage`
- **Search** — fuzzy product lookup
- **PDP / account** — product detail and account screens
- **Checkout / auth** — forms with schema validation
- **Motion** — sliders and scroll animation on marketing blocks

**Stack:** React 19 · TypeScript · Vite · React Router · Tailwind CSS · Zustand · React Hook Form + Zod

## Run locally

```bash
npm install
npm run dev
```
